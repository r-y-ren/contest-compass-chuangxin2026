## 根本目的

按《全功能实现清单-技术支持版.md》逐条兑现整个测试平台（旧实现已删、从零重做）：软件可实现项真实现（含一期全部、二期软件项），远期硬件项（信号源/频谱仪/混频 13GHz/EMI 接收机/程控衰减）以统一仪表接口+模拟后端落地，真仪表到位即插即用。**清单即台账**：每完成一个功能同步更新清单完成状态。

成功判据五条：①清单 100 条每条在代码中有着落（实现/模拟后端/范围外标注三类之一）；②清单状态列实时反映完成情况；③一键命令从注入到报告全流程可演示（无硬件时模拟模式亦可）；④pytest 全绿（防回归）；⑤报告中每个数字可溯源到本次运行的原始数据。

## 术语表

| 术语 | 精确定义 |
|---|---|
| 样式 | 干扰波形六类：单音(CW)/扫频/线性调频(chirp)/带限噪声/部分频带/脉冲 |
| 场景 | 一次测评的完整描述（YAML）：样式、频段、功率梯度、判据、后端选择 |
| 运行(run) | 场景的一次执行，产出 runs/<时间戳>/ 目录 |
| 三后端 | 仪表后端三态：b210（真硬件）/ sim（模拟）/ replay（录制回放），硬件不在位自动降级 sim |
| 插槽 | 仪表/链路/样式三类可替换组件接口；新设备=新增插件不重构 |
| KPI | 被测链路质量指标：PER 丢包率、重传计数、RSSI 信号强度（包级口径） |
| PER 口径 | 误包率=错误包/总包；EN 300 328 判据 PER≤10%；原文档 BER 比特级口径以 PER 实现（口径声明入报告） |
| 失效电平 | GB 42590 §5.11 步进中链路失效瞬间的干扰电平（P_crit） |
| 功率步进 | 自被测链路发射功率 −5dB 起、5dB 一档递增至失效 |
| 三元曲线 | 鲁棒性测评三图：PER–干扰电平、吞吐–误码、事件时间线 |
| 三路数据 | DUT-KPI（串口）∥监测谱（CH2）∥注入事件（软件），统一主机单调时钟对齐 |
| JSR | 干信比（Jamming-to-Signal Ratio），发射端标定表+监测回校换算 |
| 真值对 | SigMF 录制文件+其样式/功率/时间窗标注（dataset 索引可查） |
| 监测谱 | B210 CH2 独立天线采集的实际注入频谱统计（自校 JSR、验平坦度） |
| 模拟后端 | 远期仪表（1433D/RSA513A/混频器/EMI 接收机/程控衰减器）的软件仿真插槽 |
| 自漏 | B210 CH1 发射经空间/盒内耦合进 CH2，固定几何一次标定扣除 |
| 屏蔽盒口径 | 实验仅在金属屏蔽盒/传导耦合环境、辐射 ≤0dBm 量级、仅测自建链路 |
| 清单台账 | 《docs/全功能实现清单-技术支持版.md》状态列机制：✅完成+日期+实现锚点 |
| 分组 CV | AI 评测按录制批次分组交叉验证，防段级泄漏虚高 |
| 一键命令 | 单命令完成 注入→采集→判失效→报告，退出码 0 为成功 |

## 需求条目

> **粒度纪律：一条 R=一个可独立审查/修改/验收的功能**。P0=核心闭环（14 域中前 10 域主体）；P1=增值/远期模拟/二期项（批间可裁）。每条含数据形状（输入/输出/错误）与验收命令；完成定义统一含清单台账更新（R50 机制承载，不逐条重复）。每条末行给出对应清单条目（编号见《全功能实现清单-技术支持版.md》，I7 交付整体由 R1–R55 共同承载）。

### 域一：场景与运行框架

**R1 场景文件加载与校验器 [P0]**
- 内容：读取场景 YAML（样式/频段/功率梯度/判据/后端），校验字段完整性、取值域、频段白名单（调 R52）、功率上限；输入=场景路径；输出=规范化场景对象；错误=缺字段/越界/非白名单→退出码 2+明确指错行。
- 验收：`pytest -k scenario_validate` 全绿（合法通过、六类非法各拒一例）。
- 对应清单：B2（框架面）、I2。

**R2 运行目录与生命周期管理器 [P0]**
- 内容：创建并管理 runs/<时间戳>/ 八件套（场景副本、kpi.csv、events.jsonl、monitor.csv、SigMF 对、report.md、PNG、run.log）；运行状态机（starting→armed→running→stopping→done/failed）；任何退出路径保证发射已停、日志已落盘；输入=场景对象；输出=运行目录+结果 JSON（含退出码、耗时、后端、时钟口径）；错误=目录创建失败→退出码 1。
- 验收：`pytest -k run_lifecycle` 全绿（成功/中途异常/急停三路径，八件套与"停发射先于退出"断言）。
- 对应清单：A6、I2、I5。

### 域二：仪表后端（插槽）

**R3 仪表插槽接口与注册机制 [P0]**
- 内容：定义统一仪表接口（发射 IQ 流、接收 IQ 流、参数集、能力声明）与后端注册表；仪表/链路/样式三类插槽对称；新增后端=新文件+注册，不改核心。输入=后端名；输出=后端实例；错误=未注册名→明确报错。
- 验收：`pytest -k slot_registry` 全绿（注册/获取/未知名拒绝）。
- 对应清单：J1、L4、D7。

**R4 B210 真硬件后端 [P0]**
- 内容：UHD 驱动 B210 双通道（CH1 注入 TX／CH2 监测 RX），参数（频率/增益/采样率）下发与状态回读；一期频段 70MHz–6GHz。输入=参数集+IQ 流；输出=采集 IQ 流+硬件状态；错误=初始化/超时→异常上抛（由 R7 决定降级）。
- 验收：`pytest -k backend_b210` 全绿（在位时参数往返；不在位时 skip 并标注）。
- 对应清单：B1（一期频段）、F15。

**R5 sim 模拟后端 [P0]**
- 内容：全参数软件仿真仪表（可配置频段/带宽/增益/噪声），注入 IQ 直通内部环回供监测与链路退化模型消费；无硬件全流程可跑。输入=参数集+IQ；输出=仿真采集流；错误=同参数域校验。
- 验收：`pytest -k backend_sim` 全绿（已知输入→环回输出一致）。
- 对应清单：A5。

**R6 replay 回放后端 [P0]**
- 内容：读 SigMF 真值对按时间轴回放采集流（含时元数据），用于复现与测试。输入=SigMF 路径+倍速；输出=回放流；错误=文件损坏/时间轴断裂→报错。
- 验收：`pytest -k backend_replay` 全绿（录制→回读一致性）。
- 对应清单：I6（回读面）。

**R7 后端自动探测与降级 [P0]**
- 内容：启动时探测硬件（uhd_find_devices），在位用 b210、不在位降级 sim；当前后端标识写入运行结果、日志与 UI；硬件声称在位但初始化失败→显式报错+建议降级，**不静默 sim**。输入=探测结果；输出=后端实例+标识；错误=探测工具缺失→按 sim 处理并标注。
- 验收：`pytest -k backend_autodetect` 全绿（三态：在位/不在位/初始化失败）。
- 对应清单：F1（接入面）。

**R8 PyVISA SCPI 仪表槽位 [P1]**
- 内容：基于 PyVISA(+PyVISA-Py) 的 SCPI 仪表驱动槽位（1433D/EMI 接收机等远期真仪表的接入层），与插槽接口同构；sim 仪表可注入同槽演示。输入=VISA 地址+SCPI 序列；输出=读数；错误=仪器不在位→明确报错。
- 验收：`pytest -k visa_slot` 全绿（SCPI 序列生成与模拟仪器应答往返）。
- 对应清单：I1、J2（真机位）、J5。

### 域三：干扰样式生成

**R9 六类样式波形合成引擎 [P0]**
- 内容：单音/扫频/chirp/带限噪声/部分频带/脉冲参数化合成（J(t) 分量程序化：包络 A_k、频偏 Δf_k、相位 θ_k）；参数校验内建（频率/带宽（带限噪声 ≤56MHz）/功率域越界即拒）。输入=样式参数字典；输出=基带 IQ 流/文件；错误=越界拒绝+指明参数。
- 验收：`pytest -k styles_synth` 全绿（六样式各生成，频谱特征断言：单音单峰、扫频时变、带限噪声平坦度≤4dB、脉冲占空比）。
- 对应清单：A4、B2、B3、B4、B5、B6（时频面）。

**R10 样式注册表与快速切换 [P0]**
- 内容：样式注册表（新增样式=注册不动核心）；运行前/运行间隙切换样式 <2s（软件操作，无硬件换件）。输入=样式名+参数；输出=就绪样式实例；错误=未注册样式拒绝。
- 验收：`pytest -k styles_switch` 全绿（六样式两两切换计时 <2s）。
- 对应清单：B9。

### 域四：功率与信道模拟

**R11 功率步进执行器 [P0]**
- 内容：按 GB 42590 口径执行功率阶梯（−5dB 起、5dB 档递增至失效判据触发），每档写注入事件（时间戳+电平+档号）至 events.jsonl；失效即停。输入=梯度参数+失效判据回调；输出=事件流；错误=档位越界/后端增益不可达→先停发射再报错。
- 验收：`pytest -k power_ladder` 全绿（步进序列、事件时间线、失效即停）。
- 对应清单：B6（功率面）、D3（调度面）。

**R12 粗细档信道拼接器 [P0]**
- 内容：30dB 手调衰减器（接入/旁路两态，事件记录）+软件增益细档的拼接调度；一期总衰减 30dB+软件增益（60dB 全量程由 R43 模拟演示）。输入=目标衰减量；输出=档位组合+事件；错误=请求衰减超出可达范围→拒并给出可达范围。
- 验收：`pytest -k channel_ladder` 全绿（请求→组合映射、越界拒绝）。
- 对应清单：D1、D3、D5（一期量程）、D7（数字信道执行面）。

**R13 距离-损耗映射器 [P0]**
- 内容：对数距离路径损耗 L(d)=L(d₀)+10n·log₁₀(d/d₀)+X_σ 以功率台阶等效实现（距离→目标损耗→档位组合；n/X_σ 参数化）；映射远场微弱→近场阻塞的演变序列。输入=距离序列/模型参数；输出=损耗-档位计划；错误=距离超可模拟范围→提示可达距离域。
- 验收：`pytest -k pathloss_map` 全绿（已知 n/d₀ 数值断言、演变序列单调）。
- 对应清单：D2、D4、D6（一期量程）。

**R14 JSR 标定与换算器 [P0]**
- 内容：发射端增益→实际注入功率标定表构建与查询（实测前【待实测】占位、禁止预写）；JSR=干扰/信号功率比换算；支撑干信比梯度场景。输入=增益档/链路信号功率；输出=估计注入功率/JSR；错误=标定表缺失→拒绝 JSR 场景并提示先标定。
- 验收：`pytest -k jsr_calibration` 全绿（合成标定表→换算断言、缺表拒绝）。
- 对应清单：B7（标定面）、D4（梯度面）。

### 域五：时钟参考

**R15 时钟参考探测与口径报告 [P1]**
- 内容：探测 B210 板载 GPS 锁定/外接 10MHz/PPS 可用性；可用则启用驯服，不可用降级主机单调钟；时钟口径写入 run.log 与报告脚注。输入=无（探测）；输出=时钟状态枚举+时基选择；错误=探测失败不阻塞（降级+标注）。
- 验收：`pytest -k clocking` 全绿（状态枚举、降级路径、脚注字段）。
- 对应清单：B8（一期口径）、J3。

### 域六：监测通道

**R16 监测谱采集器 [P0]**
- 内容：CH2 监测流采集与统计落盘 monitor.csv（时间戳+频率 bin+功率）；56MHz 带宽边界内建：2.4G 整段（83.5MHz）自动限带或分段、5.8G 单信道段。输入=采样参数；输出=monitor.csv 流；错误=带宽越界→自动限带并记录口径。
- 验收：`pytest -k monitor_capture` 全绿（sim 已知谱→还原特征频率；超带宽自动限带）。
- 对应清单：E1（一期）、E3。

**R17 频谱统计与质量核验器 [P0]**
- 内容：SNR 估计（公式(4)：P_signal/(P_noise+P_interference)）、JSR 反演、带限噪声平坦度核验（≤4dB）、杂散可观测性口径（监测底噪入报告）。输入=monitor 数据+参考信号参数；输出=统计行（SNR/JSR/平坦度）；错误=参考缺失→只出功率统计并标注。
- 验收：`pytest -k spectrum_stats` 全绿（合成谱 SNR 断言、平坦度越限报警）。
- 对应清单：C5（一期监测级）、E2、E4（可观测面）、G11。

### 域七：被测链路

**R18 ESP32 WiFi 链路驱动 [P0]**
- 内容：ESP32 固件（UDP 定长流+RSSI 周期上报，PlatformIO 构建）与主机侧串口解析器；KPI=PER/重传/RSSI。输入=串口流；输出=KPI 样本（时间戳+指标）；错误=串口断开/帧损坏→先停发射再退出+日志。
- 验收：`pytest -k dut_esp32` 全绿（样本帧解析、PER 计算、断开处置）。
- 对应清单：A7、F2、F3（WiFi 面）。

**R19 NRF24 链路驱动 [P0]**
- 内容：NRF24 固件（RPD 1bit+ARC_CNT/PLOS_CNT 计数上报）与主机解析；KPI=丢包/重传（无 RSSI，指标口径不写信号强度）。输入=串口流；输出=KPI 样本；错误=同 R18。
- 验收：`pytest -k dut_nrf24` 全绿（计数解析、口径字段断言）。
- 对应清单：F3（NRF 面）。

**R20 sim 链路退化模型 [P0]**
- 内容：无硬件时的 KPI 发生器：由当前注入参数（样式/功率/频偏）驱动的 PER 退化模型（含失效悬崖），供 sim 全流程与 R23/R25 验收；模型参数【待实测】校准位。输入=注入事件流；输出=仿真 KPI 流；错误=模型域外输入→夹紧并标注。
- 验收：`pytest -k dut_sim` 全绿（PER 随功率单调、悬崖档位可控）。
- 对应清单：F1（sim 面）、F7（模型面）。

**R21 KPI 数据模型与 PER 口径 [P0]**
- 内容：两链路+sim 统一的 KPI 数据模型（包级口径，EN 300 328 判据 PER≤10%）；BER 比特级口径以声明实现（F13 空缺数字按"实测后定、禁止预写"处置，报告出口径脚注）。输入=各源 KPI 样本；输出=统一 kpi.csv 行+口径元数据；错误=异源字段冲突→拒并指源。
- 验收：`pytest -k kpi_model` 全绿（异源归一、判据计算、口径字段）。
- 对应清单：F2（口径面）、F4、F5、F13。

## 非功能约束

| 约束 | 判据 |
|---|---|
| 合规红线 | 超功率/超频段/非白名单配置一律拒绝；报告必含四项口径声明（R52 用例） |
| 实时性 | KPI 端到端刷新 <500ms（sim 实测记录入 run 结果 JSON；清单指标 11） |
| 样式切换 | <2s（R10 计时用例） |
| 可扩展性 | 仪表/链路/样式三插槽：新增后端=新插件文件+注册，不改核心（R3/R43 用例：后端即插即换） |
