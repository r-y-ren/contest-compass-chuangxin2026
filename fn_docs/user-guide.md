## 环境配置

虚拟环境已随仓库带好（`fn_work/.venv`，不入 git）。换机器或删掉后按此复建（依赖清单 `fn_work/requirements.txt` 已入库）：

```bash
cd fn_work
python3 -m venv --system-site-packages .venv    # 必须带此参：继承系统 UHD/GNU Radio 绑定
.venv/bin/pip install -r requirements.txt       # 16 个包（含演进轮新增 markdown/playwright）
.venv/bin/playwright install chromium           # 仅浏览器自动化测试用（下载约 114MB，解压后约 660MB（含 headless_shell），装进 ~/.cache）
```

验证：`.venv/bin/python -c "import markdown, playwright, fastapi"` 应无输出（即成功）。

## 快速开始

一条命令起操控台，浏览器打开就是七页全能力界面（断网也可用——全部页面资源已本地化）：

```bash
cd fn_work
.venv/bin/python -c "from src.serve_console.serve_console import serve_console; serve_console({'scenario_dir': 'scenarios', 'report_root': 'runs', 'port': 8000, 'dry_run': False})"
```

浏览器访问 `http://localhost:8000/pages/index`（Ctrl+C 关服务）。顶部导航七页：**总览 / 运行 / 报告 / 数据 / AI / 仪表 / 台账**。往 `scenarios/` 放场景文件（写法见 README.md）后**重启服务**，运行页卡片才会出现（卡片为装配期快照，运行期放入不自动刷新；页内场景编辑器保存的场景即时可见）。

## 使用方法

### 运行页——发起测试与实时曲线
1. 场景卡片区点「启动运行」：真实执行一次测评（结果落 `runs/`、报告自动生成），页面每秒轮询、跑完状态区显示结果与报告路径。
2. **场景编辑器**：页面上直接新建/编辑/删除场景——表单模式（字段控件）或 YAML 文本模式切换；写错（缺安全声明/超功率等）服务端校验错误会逐条上屏。多频段场景只能用 YAML 模式保存（表单会警示并阻止覆盖）。
3. **实时三路曲线**：运行期间 KPI 折线、频谱瀑布、事件时间线三图同屏滚动（发射窗内采到注入信号本体——模拟模式录音含样式调制内容；发射窗外回放低功率底噪块——两类来源以功率量级内容级可辨，环回块约 -0.1dB（样本域 dB）vs 底噪块约 -140.1dB（样本域；与 dBm 口径的换算取决于采集增益标定，两域分隔 140dB 即"内容级可辨"的实测依据））。
4. **急停按钮**：第一动作先停发射再终止编排，页面反馈如实显示（发射已停/无后端在途/失败原因）。

### 报告页——站内读报告与跨轮对比
1. 运行列表（时间/场景/样式/后端/状态/失效电平）→ 点行钻取整份报告：正文渲染、三张曲线图、原始数据下载、**溯源校验徽标**（报告数字可回查原始数据）。EMC 场景的报告自动含对应摸底节——传导（读数/裕量表+合规判定）、辐射（谱表+洁净度+补偿注记）、扫频（点表），标题随流程对号（R89）。
2. 勾选多轮运行「对比」：多样式失效电平对比表+最薄弱样式/频点结论；样本不足自动降级单样式并标注。

### 数据页——录音库与一键回放
1. 点「重建索引」扫描 `runs/` 下的带标注录音（SigMF 真值对），卡片显示样式/功率/时长/来源运行，可按样式/日期过滤。
2. 卡片点「回放此条」：用当时的真实录音重跑一遍（backend=replay），全程走真实管线、红线声明不全的录音会被拒绝。模拟模式新录音（R88 起）含发射窗内的注入信号本体——不同样式的录音谱形可辨，攒样训练/识别演示的数据面与真机口径一致。

### AI 页——训练/评测/识别
1. 训练：选远程显卡机或本机、可勾 dry_run 试跑；进度轮询、模型列表在页；样本不足会如实报"拒训"。
2. 评测：分组交叉验证（防泄漏口径），混淆矩阵与 Macro-F1 表格化呈现，数据划分有夸大嫌疑时如实警告。
3. 识别：选任一历史运行或录音，当场判它是哪种干扰并给置信度，与录制时的"标准答案"对照显示命中与否（无模型时提示先训练，不阻塞）。

### 仪表页——五台模拟仪表+EMC+标定+二期演示
1. 五台远期仪表（信号源/频谱仪/混频/EMI 接收机/程控衰减器）面板：打开→读数演示→关闭，超量程如实标注；VISA 槽位状态总览。
2. EMC 三流程（传导/辐射/扫频）：表单发起→图谱+强制模拟口径声明，结果自动进该轮报告的对应摸底节（缺限值线等情形如实标"未判定"）。
3. 标定看板：三类标定表当前状态（未实测的如实显示【待实测】），可一键用合成数据把标定流程走一遍（不写真实表）。
4. 二期演示：SITL 映射预览（dry_run）/ RL 策略冒烟（不收敛自动回退如实标注）/ RFF 管道四阶段进度。

### 台账页——完成度与审计
清单 done/total 明细、锚点审计（打了 ✅ 的条目代码是否真实在）、代码注释率——只读展示，网页发起的运行不会写清单。

### 命令行等价入口（无浏览器场景）
一键演示与场景文件跑法见 README.md「快速开始」三式；所有命令以 `.venv/bin/python` 开头、在 `fn_work` 目录执行。

## 已知限制

1. **sim 发射窗外数据为合成底噪**：采集窗与发射窗对齐（R88 闭合）——发射窗内录音/监测采到含样式调制的环回信号，窗外仍回低功率底噪块（与发射环回块以功率量级内容级可辨：环回约 -10dB 级 vs 底噪 -110dBm 级；synthetic 标注仅存在于后端内存块元数据，不落盘）；真机（B210）路径同一编排，实测随真机复查阶段。
2. **标定表未实测**：三类标定表保持【待实测】占位，标定看板如实显示；真机标定后自动转实值。
3. **对抗审查留档的低危项**：`/api/demo/sitl` 的 run_id 传 `.` 已被围栏拦截（400 运行无 KPI 数据——R72 围栏在位，原自曝项已失效）；责任文档对账函数可被同号伪块头欺骗（本地工具，非安全面）；RL 演示的"收敛"判据为半程均值比较（已如实标注非正式）。
4. **AI 训练真模型与识别限界**：当前为轻量替身模型（cnn_dummy 口径），真 CNN 训练经远程算力路径（remote-compute）时可用。sim 录音自 R88 起含样式调制内容（谱形随样式可辨）——训练/评测**流程**可全程 sim 攒样演示；但**识别语义**存在已知限界：平台录音的阶梯通断包络会命中规则判据首条，sim 录音识别恒判 pulse（24/24 实测）——"识别得准"的语义演示需显式合成 IQ 样本（已证）或真机录音（随 R87 验证）。
5. **终端 TUI/CLI 展示**：不做（用户裁决沿用 web）；run_demo 是唯一 CLI 入口。
6. **固件烧录**（ESP32/NRF24 PlatformIO）按 Ruling⑱ 顺延未交付，真机链路驱动代码与测试在位。
7. **真机侧交窗实证随 R87**：统一编排对 B210 是采集窗提前打开（行为不劣化），但 B210 块时间戳为后端单调序号域（交窗时间基础 sim 侧成立）——真机口径决策与发射窗缓冲上界（档多+dwell 长时无界）随真机复查阶段一并定。
8. **演示手册 v2（R90+R94 设备真值）**：docs/功能演示手册.md 为单一真机方案（**19 项**设备全集清单+大仪器替代边界节+唯一连接图，被测链路 WiFi/NRF24 换固件二选一）、26 章三件套（设备说明集中于总章）。R94 起 B210 接法按说明 PDF 真值：**射频四口全 SMA（发=TRX1 直连衰减器、监测=RX2 直连天线，无 MMCX 转接）；MMCX 口仅 GPS/PPS/10M**（GPS 天线用公转母线）；面板丝印 TRX1/RX2 在软件层对应 UHD 天线逻辑名 TX/RX 与 RX2（场景 antenna 参数用逻辑名）；新主机首次需替换 usrp_b210_fpga.bin（K7 版，本演示机已替换）、GPSDO 插槽已移除。
9. **急停后的报告为占位符**：急停/中止的运行其 report.md 停在占位文案（正文由收尾阶段生成是正常完成路径的行为）；急停轮的产出以 events.jsonl 与 result.json 为准（stopped 状态在列表中显示为 failed，未区分用户主动停）。
