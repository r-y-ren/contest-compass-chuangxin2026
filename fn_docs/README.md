# 无人机链路抗干扰测试平台（重做版）

> 面向队友的零术语说明。技术细节与验收口径见 requirements.md；功能全集与完成进度见《../docs/全功能实现清单-技术支持版.md》。

## 这个东西是干什么的

我们自己搭两条小型无线链路（一块 ESP32 跑 WiFi、一块 NRF24 跑数传），当作"无人机通信链路"的替身。用一台软件无线电设备（USRP B210）按设定好的方式朝它们发干扰，全程记录链路表现变差的过程，最后自动出报告：什么样的干扰、多强、链路坏到什么程度、机器认不认得。

没接硬件也能玩：软件自带"模拟模式"，会用一台假想的 B210 走完从发干扰到出报告的全部流程，用于演示、教学和自动化测试。以后买到真的大仪表（信号源、频谱仪、13GHz 混频器、EMI 接收机），插上就能用，软件不用推倒重写——每类仪表都有一个"插槽"，真仪表是一根插槽，模拟器也是一根插槽。

这次的特别规矩：**《全功能实现清单-技术支持版》就是进度账本**。每做完一个功能，清单里对应那一行就会标上"已完成+日期+代码在哪"，打开清单就能看到整个项目做到了哪一步。

## 工作流程（从开机到报告）

1. **准备**：把 ESP32 和 NRF24 用 USB 线接到主机，B210 接 USB3 线，天线按固定位置摆进金属屏蔽盒。（如果只是演示或跑测试，跳过这步，直接用模拟模式。）
2. **启动**：双击启动脚本（或一条命令），浏览器自动打开操控台——之后全程只用鼠标。软件会自动检查：B210 在不在？在就用真硬件，不在就切模拟模式，界面上一眼能看到当前用的是哪种。
3. **选场景**：点一张场景卡片（比如"国标·噪声干扰""国标·单音干扰"），或者自己拖滑杆调：干扰样式（六选一）、起始功率、每档加多少、每档停留多久。
4. **一键执行**：点"开始"。软件按场景设定发出干扰，同时盯住三路信息——被测链路的质量（丢包/重传/信号强度）、监测天线看到的实际干扰谱、每次功率调整的时间点，全部对齐到同一个时钟记录下来。功率一级一级往上加，加到链路失效就停，失效那一刻的干扰强度自动记为"失效电平"。
5. **安全兜底**：过程中任何时候出错或点"急停"，软件第一件事是闭嘴不发，然后才退出并留下完整日志。
6. **出报告**：跑完自动生成报告（网页里直接看，也存成文件）：鲁棒性曲线、失效电平表、频谱图、AI 识别结果，还有一句固定声明——本测试在屏蔽盒内进行、只测我们自己的链路、不是正式的 EMC 认证。
7. **对账**：报告页底部有"清单完成度"入口，点开就是《全功能实现清单-技术支持版》的最新状态——每条功能后面跟着 ✅ 日期和代码位置，还没做的标 ⬜。

## 项目功能（做什么、做到什么程度）

1. **六类干扰样式**：单音、扫频、线性调频（chirp）、带限噪声、部分频带、脉冲。全软件生成，切换不用动硬件，两秒内换完。带宽自动限制在设备能力内（56MHz），不会"想要的波形造不出来"。
2. **功率阶梯**：从"比链路自身信号弱 5dB"起步，每档加 5dB，直到链路失效——这是照搬国家标准 GB 42590 的测法，测出来的"失效电平"可以直接写进报告。
3. **双链路指标**：ESP32 链路看丢包率/重传/信号强度；NRF24 链路看丢包/重传计数。指标一律用"包"的口径（行业判据：丢包超 10% 算失效）。
4. **三路对齐**：链路指标、监测谱、注入事件三条数据流盖同一个时间戳，事后能对上"哪一刻加了干扰、哪一刻链路开始崩"。
5. **真值数据集**：每次实验的原始无线电信号连同"当时发的是什么干扰、多强"的标注一起存档（SigMF 标准格式），攒成一套带标准答案的数据集——这是公开数据里没有的东西。
6. **AI 认干扰**：用数据集训一个"看图认干扰"的模型（七分类：六种样式+无干扰），训练放在远程的 4070 显卡机上跑；评测按"同一批录音不跨组"的严格口径，防止虚高。
7. **EMC 摸底（模拟）**：电磁兼容测试的流程先做成模拟版（假想的 EMI 接收机+LISN），跑通"传导/辐射摸底"的全流程演示；真接收机到位后换插槽即测。
8. **远期仪表模拟**：信号源、频谱仪、13GHz 混频、程控衰减器，每一台都有一个模拟后端——清单里标"远期"的条目现在就能在模拟模式下走完全流程。
9. **校准补偿**：发射端功率标定表+监测通道回校；功率读数自动扣掉线损和天线系数（照原文档公式(6)）。
10. **Web 操控台**：场景卡片、滑杆调参、实时曲线（半秒内刷新）、急停按钮、报告中心、清单完成度入口。
11. **一键命令**：不开网页也能一条命令跑完"注入→采集→判失效→出报告"，退出码 0 算成功——自动化测试和验收全靠它。
12. **合规红线**：软件里写死三件事——功率配置不超过限值、只允许屏蔽盒环境（界面提示）、只测自建链路；报告里自动带免责声明。
13. **进阶方向（二期软件项）**：①把实测的"功率-丢包曲线"喂给无人机模拟器（ArduPilot SITL），让模拟飞机体验真实链路退化；②用强化学习自动出干扰策略；③射频指纹识别（认出"这是哪台设备发的"），训练走远程算力。
14. **清单台账**：每完成一个功能，《全功能实现清单-技术支持版》对应条目标 ✅+日期+代码位置，统计节自动口径对齐——清单即账本，打开就知道做到哪了。
